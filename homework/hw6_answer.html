1 Textbook Exercises

1.1 Exercise 12.8

  1. Given the simultaneous equations,

\[ \left\{\begin{aligned} &Q^s_i = \beta_0 + \beta_1 P_i + u^s_i \\ &Q^d_i = \gamma_0 + u^d_i \end{aligned}\right. \]

by equilibrium condition \(Q^s_i = Q^d_i \overset{\Delta}{=} Q_i\), we get:

\[ \beta_0 + \beta_1 P_i + u^s_i = \gamma_0 + u^d_i \]

Solving for \(P_i\) and \(Q_i\):

\[ \begin{aligned} &P_i = \frac{\gamma_0 + u^d_i - \beta_0 - u^s_i}{\beta_1} \\ &Q_i = \gamma_0 + u^d_i \end{aligned} \]

Since:

\[ \text{Cov}(P, u^s) = \text{Cov}\left(\frac{\gamma_0 + u^d - \beta_0 - u^s}{\beta_1}, u^s\right) = \text{Cov}\left(\frac{-u^s}{\beta_1}, u^s\right) = -\frac{1}{\beta_1}\text{Var}(u^s) \]

We have \(\text{Corr}(P, u^s) \neq 0\) and conclude that the price variable is endogenous.

  1. We can take the probability limit on the OLS estimator:

\[ \hat{\beta}_1 = \frac{\sum_{i=1}^{n} (P_i - \bar{P})(Q_i - \bar{Q})}{\sum_{i=1}^{n} (P_i - \bar{P})^2} = \frac{\frac1n \sum_{i=1}^{n} (P_i - \bar{P})(Q_i - \bar{Q})}{\frac1n \sum_{i=1}^{n} (P_i - \bar{P})^2} \overset{p}{\to} \frac{\text{Cov}(P, Q)}{\text{Var}(P)} \]

and note that:

\[ \frac{\text{Cov}(P, Q)}{\text{Var}(P)} = \frac{\text{Cov}(P, \beta_0 + \beta_1P + u^s)}{\text{Var}(P)} = \beta_1 + \frac{\text{Cov}(P, u^s)}{\text{Var}(P)} \]

Since \(\text{Cov}(P, u^s) \neq 0\), we conclude that \(\hat{\beta}_1\) is inconsistent.

  1. \(\gamma_0\) can be estimated by OLS easily since it’s equivalent to the sample mean of \(Q\).

However, to estimate \(\beta_0\) and \(\beta_1\), we need an instrumental variable, which should be correlated with \(P\) but uncorrelated with \(u^s\). In this case, \(Q\) can serve as the instrument because demand is completely inelastic (so that \(Q\) is not affected by shifts in supply).

1.2 Exercise 12.9

  1. While it is plausible that having more secure property rights affects a country’s level of income, it is also plausible that richer countries can afford institutions that protect property rights. Thus, there is a problem of simultaneous causality bias. According to this theory, as richer countries can afford secure property rights, OLS estimates might be overestimated.

  2. Denote the instrumental variable settler mortality as \(z\). We need to check the following conditions:

  • Exogeneity: settler mortality (\(z\)) is not directly related to a country’s recent income (\(u\)). Thus, \(z\) satisfies \(\text{Cov}(z, u) = 0\).
  • Relevance: settler mortality (\(z\)) affected European settlement, and subsequently led to the establishment of early institutions for securing property rights(\(x\)), which have persisted until the present day. Hence, \(z\) satisfies \(\text{Cov}(z, x) \neq 0\).

1.3 Exercise 12.10

By taking probability limit on the TSLS estimator:

\[ \hat{\beta}^{TSLS}_1 = \frac{\sum_{i=1}^{n} (Z_i - \bar{Z}) (Y_i - \bar{Y})}{\sum_{i=1}^{n} (Z_i - \bar{Z}) (X_i - \bar{X})} = \frac{\frac1n \sum_{i=1}^{n} (Z_i - \bar{Z}) (Y_i - \bar{Y})}{\frac1n \sum_{i=1}^{n} (Z_i - \bar{Z}) (X_i - \bar{X})} = \overset{p}{\to} \frac{\text{Cov}(Z, Y)}{\text{Cov}(Z, X)} \]

and note that:

\[ \frac{\text{Cov}(Z, Y)}{\text{Cov}(Z, X)} = \frac{\text{Cov}(Z, \beta_0 + \beta_1 X + \beta_2 W + u)}{\text{Cov}(Z, X)} = \beta_1 + \frac{\beta_2 \text{Cov}(Z, W)}{\text{Cov}(Z, X)} \]

  1. If \(\text{Cov}(Z, W) \neq 0\), the IV estimator is not consistent. The first student is correct.

  2. If \(\text{Cov}(Z, W) = 0\), the IV estimator is consistent. The second student is correct.

1.4 Exercise 13.3

  1. The average treatment effect on test scores is

\[ \bar{X}_{\text{treatment}} - \bar{X}_{\text{control}} = 1348 - 1395 = -47 \]

  1. Prepare:

\[ \left\{\begin{aligned} &H_0: p^{\text{treatment}}_{\text{men}} = 0.5 \\ &H_1: p^{\text{treatment}}_{\text{men}} \neq 0.5 \end{aligned}\right. \]

Let the significance level be 5%.

Calculate:

\[ t^* = \frac{\hat{p} - p_0}{\sqrt{\frac{p_0 (1 - p_0)}{n}}} = \frac{0.6 - 0.5}{\sqrt{\frac{0.5 (1 - 0.5)}{100}}} = 2 \]

Conclude:

Since \(|t^*| > Z_{0.025} = 1.96\), we reject \(H_0\). There is a significant evidence of nonrandom assignment.

1.5 Exercise 13.7

From the population regression, we know that:

\[ \begin{aligned} Y_{i2} &= \alpha_i + \beta_1 X_{i2} + \beta_2 W_i + \beta_0 + v_{i2} \\ Y_{i1} &= \alpha_i + \beta_1 X_{i1} + v_{i1} \end{aligned} \]

By taking differences, we can obtain:

\[ \underbrace{Y_{i2} - Y_{i1}}_{\Delta Y_i} = \beta_0 + \beta_1 \underbrace{(X_{i2} - X_{i1})}_{\Delta X_i} + \beta_2 W_i + \underbrace{(\nu_{i2} - \nu_{i1})}_{\Delta \nu_i} \]

This eliminates the individual fixed effects (\(\alpha_i\)), allowing for consistent estimation of \(\beta_1\). Additionally, note that we can define \(X_i \equiv \Delta X_i\) since it’s actually binary, so this can be rewritten as:

\[ \Delta Y_i = \beta_0 + \beta_1 X_i + \beta_2 W_i + \Delta \nu_i \]

which is equation (13.6) in the case of single \(W\) regressor.

2.6 IV: Conditions

There are two conditions:

  • Relevance: \(\textit{motheduc}\) and \(\textit{fatheduc}\) should be correlated with \(\textit{educ}\).

  • Exogeneity: \(\textit{motheduc}\) and \(\textit{fatheduc}\) should be uncorrelated with the error term.

reg_1g <- ivreg(

2.8 IV: Overidentification Test

# residuals
resi <- reg_1g$residuals

# calculate J statistics by partial F test of residual on IVs
reg_1h <- lm(
  formula = resi ~ south + married + exper + I(exper^2) + nearc4 + fatheduc + motheduc,
  data = card
)
test_1h <- linearHypothesis(
  reg_1h,
  c("nearc4 = 0", "fatheduc = 0", "motheduc = 0"),
  test = "F"
)

# Note that J = m * F ~ chisquared(m-k), where k = #(endogeneous variables) and m = #(instrumental variables)
J <- 3 * test_1h[2, 5]
pchisq(J, df = 3-1, lower.tail = FALSE)
[1] 0.5151249

Because the \(p\)-value is greater than 0.05, under the 5% significance level, we do not reject \(H_0\). So we conclude that all instruments are exogenous.
