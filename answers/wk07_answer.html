1 Gambling Apocalypse Kaiji (賭博默示錄)

Kaiji is gambling with Tonegawa in E-Card.

E-Card Game Rule

In E-Card, one side holds 4 Citizen cards and 1 Emperor card, while the other side holds 4 Citizen cards and 1 Slave card. Each player plays one card in each round.

The rule is:

  • Emperor beats Citizen
  • Citizen beats Slave
  • Slave beats Emperor

If the Slave catches the Emperor in a round, the player on the slave side wins. Otherwise, the player on the emperor side wins. Because the slave_side is at a disadvantage, winning from that side is much harder.

As the games go on, Kaiji appears to be dominated by Tonegawa, so he begins to suspect that Tonegawa is cheating. He records some of his feelings and observations during the game. The dataset contains the following variables (in this practice, you need to generate the dataset yourself):

  • game_num: The game number from 1 to 50.
  • side: Kaiji’s side in that round, either emperor_side or slave_side. Kaiji’s side in each round is random: it is emperor_side if \(X < 0.5\), where \(X \sim \text{Unif}(0,1)\).
  • kaiji_stress: Kaiji’s stress level during the round. He feels more stressed on the emperor_side, so kaiji_stress follows \(N(0.5, 0.4^2)\) on the slave_side and \(N(0.7, 0.4^2)\) on the emperor_side.
  • tonegawa_pressure: The pressure from Tonegawa during the round. It follows \(N(0.5, 0.3^2)\).
  • decision_time: How long Kaiji hesitates before making his decision (by minutes). It follows \(\text{Exp}(2)\).
  • if_win: Whether Kaiji wins the round (1 = win, 0 = lose). This variable is generated by a helper function saved in calc_win.R, which depends on side, kaiji_stress, tonegawa_pressure, and decision_time. (right click here)

Kaiji suspects that Tonegawa is using some illegal method to infer his strategy, for example, by detecting his blood pressure. If Kaiji’s hypothesis is correct, then his win probability should depend on the stress level he feels, but not on how confident Tonegawa is or how long he takes to make a decision.

Follow the instructions below to help Kaiji test his hypothesis:

  1. Before you begin, complete the setup:

    • Open the project you created for the TA Session by clicking on .Rproj (if you do not have one, create it).
    • Open a new script and save it in the script folder.
    • Make sure the helper file calc_win.R is saved in the script folder.
    • Install and call the packages tidyverse, estimatr, and car.
    • (Optional) Remove all objects from the environment using rm(list = ls()).

  2. Set the random seed to 123, and let the number of rounds be 50.

  3. Create a dataframe called e_card_data that contains game_num, side, kaiji_stress, tonegawa_pressure, and decision_time. Standardize the last three variables using scale().

  4. Source the helper file calc_win.R and combine the output into e_card_data (do not copy and paste the function inside!).

  5. Fit a robust linear regression model called reg_win with if_win as the response variable and kaiji_stress, tonegawa_pressure, decision_time, and side as the predictors. Print the regression summary.

  6. Test the null hypothesis \(H_0:\beta_1 = \beta_2\) where:

    • \(\beta_1\) is the coefficient on kaiji_stress
    • \(\beta_2\) is the coefficient on tonegawa_pressure Can you reject the null hypothesis that the coefficients on kaiji_stress and tonegawa_pressure are equal?

  7. Change the number of random seed (to any number you like), does the result stays similar?

1.1 TA Answer Code: Po-Hsien Kang


rm(list = ls())

library(tidyverse)
library(estimatr)
library(car)

set.seed(123)

n <- 50

game <- seq_along(1:n)
side <- if_else(runif(n) < 0.5, "emperor_side", "slave_side")

kaiji_stress <- rnorm(
  n,
  mean = if_else(side == "slave_side", 0.5, 0.7),
  sd = 0.4
)

tonegawa_pressure <- rnorm(n, mean = 0.5, sd = 0.3)
decision_time <- rexp(n, rate = 2)

e_card_data <- data.frame(
  game_num = game_num,
  side = side,
  kaiji_stress = scale(kaiji_stress),
  tonegawa_pressure = scale(tonegawa_pressure),
  decision_time = scale(decision_time)
)

source("practices/calc_win.R")

e_card_data <- cbind(e_card_data, calc_win(e_card_data))

reg_win <- lm_robust(
  if_win ~ kaiji_stress + tonegawa_pressure + decision_time,
  data = e_card_data
)

summary(reg_win)

linearHypothesis(
  reg_win,
  hypothesis.matrix = "kaiji_stress = tonegawa_pressure",
  test = "F"
)

library(tidyverse)
library(estimatr)
library(car)
rm(list = ls())


# Gen data
#================
set.seed(123)
# set.seed(20260516)
game_num = c(1:50)
             
side_rand = runif(50)
side <- ifelse(side_rand < 0.5, "emperor_side", "slave_side")

kaiji_stress <- ifelse(
  side == "slave_side",
  rnorm(50, 0.5, 0.4),
  rnorm(50, 0.7, 0.4)
)%>% scale() %>% as.numeric()

tonegawa_pressure <- as.numeric(scale(rnorm(50, 0.5, 0.3)))
decision_time <- as.numeric(scale(rexp(50, 2)))

e_card_data <- data.frame(
  game_num,
  side,
  kaiji_stress,
  tonegawa_pressure,
  decision_time
)

source("script/calc_win.R")
if_win <- calc_win(e_card_data)
e_card_data <- cbind(e_card_data, if_win)


# Hypo test
# ==================
reg_win <- lm_robust(
    data = e_card_data,
    if_win ~ side + kaiji_stress + tonegawa_pressure + decision_time
)
  
linearHypothesis(
    reg_win, c("kaiji_stress = tonegawa_pressure"), test = "F"

1.3 TA Answer Code: Tom

library(estimatr)
library(car)

set.seed(123)
n <- 50

e_card_data <- data.frame(
  game_num = 1:n
)

side_draw <- runif(n)
e_card_data$side <- ifelse(side_draw < 0.5, "emperor_side", "slave_side")
e_card_data$kaiji_stress <- ifelse(
  e_card_data$side == "slave_side",
  rnorm(n, mean = 0.5, sd = 0.4),
  rnorm(n, mean = 0.7, sd = 0.4)
)
e_card_data$tonegawa_pressure <- rnorm(n, mean = 0.5, sd = 0.3)
e_card_data$decision_time <- rexp(n, rate = 2)


source("script/calc_win.R")


e_card_data$kaiji_stress <- as.numeric(scale(e_card_data$kaiji_stress))
e_card_data$tonegawa_pressure <- as.numeric(scale(e_card_data$tonegawa_pressure))
e_card_data$decision_time <- as.numeric(scale(e_card_data$decision_time))
e_card_data$side <- factor(
  e_card_data$side,
  levels = c("slave_side", "emperor_side")
)
e_card_data <- cbind(e_card_data, calc_win(e_card_data))


reg_win <- lm_robust(
  if_win ~ kaiji_stress + tonegawa_pressure + decision_time + side,
  data = e_card_data
)

summary(reg_win)


linearHypothesis(
  reg_win,
  "kaiji_stress = tonegawa_pressure",
  test = "F"
)
